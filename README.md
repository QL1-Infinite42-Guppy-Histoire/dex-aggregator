# DEXアグリゲーター（42 Chain / QL1）

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**サイト: https://ql1-infinite42-guppy-histoire.github.io/dex-aggregator/**

42 Chain（Infinite、EVM 421018）と QL1（EVM 766）で、トークンの交換（スワップ）のときに
**いちばん多く受け取れるルート（交換の通り道）を全部のプールから探す**サイトです。

例：USDT → 42 は直接交換できるだけでなく、USDT → FISH → 42 のように途中で別の
トークンを経由する道もあります。金額によって多い方が変わるため、このサイトは
候補を全部見積もって並べ、選んだルートでそのまま交換できます。

## 使い方

1. チェーン（42 Chain / QL1）を選ぶ
2. 出すトークン・金額・受け取るトークンを選ぶ（金額は 25% / 50% / 75% / MAX チップでも指定可）
3. 「ルートを比べる」を押す → ルート一覧が受け取れる量の多い順に並ぶ
4. 好きなルートを選び、MetaMask を接続して「このルートで交換する」

一覧に無いトークンは、CA（コントラクトアドレス）を貼るとチェーンから読み取って追加できます（このブラウザに保存されます）。

## ルートの探し方

- DEX ルーター（42 Chain: Don't Panic / Nutri-Matic、QL1: QomSwap、どちらも Uniswap V2 方式）の
  `getAmountsOut` を、以下の全候補で実際に叩いて比較します。
  - 直接（A → B）
  - 1つ経由（A → X → B）: X はチェーンの基準トークン全部
    （42 Chain: 42 / USDT / USDC / FISH / QOM / ZAP / PANIC、QL1: WQOM / qUSDT / qUSDC / qDAI / QSWAP）
  - 2つ経由（A → X → Y → B）: 基準トークンの全ペア
- 各ルートには、直接ルートとの差（%）、交換回数、プール残高から計算した
  「値段の下がり幅（手数料＋価格への影響）」を表示します。
- 直接プールが無いペアでも、経由ルートがあれば成立します（例: QL1 の BABY → KET は WQOM 経由）。

## 正直な限界（分割について）

金額を複数のルートに分けて一度に交換する「分割」（例: 70% を直接、30% を経由ルート）は、
**専用のアグリゲーター・コントラクトが無いと実行できません**。このチェーンにはまだ
そのコントラクトが無いため、このサイトは分割を偽って実行しません。

代わりに、上位2ルートに 50/50 で分けた場合の見積もりが単一ベストより多いときだけ、
「分割したら（参考）」として金額を表示します（実行はできません）。

## その他

- 見積もりだけならウォレット不要。交換のときだけ MetaMask を使います。
- スリッページ（見積もりからのズレの許容幅）は 0.5% / 1% / 3% / 自由入力。有効期限20分。
- このサイト自体は手数料を取りません。交換は各 DEX のルーターと直接やり取りします。
- プールが小さいトークンでは結果がズレやすくなります。小額で試してから使ってください。

## 開発

ビルド不要の静的サイトです（`docs/` がそのまま GitHub Pages）。

```sh
node probe/probe.cjs     # ライブ見積もり・calldata構築の検証（送信はしません）
node tools/harness.cjs   # 出荷コードを DOM スタブ上で動かす検証
```
