クロスチェーン交換（QL1 ⇔ 42 Chain）

別のチェーンのトークンに交換します。進み方は「交換 → ブリッジで送る → 到着を待つ → 最後の交換」の4ステップで、各ステップで自分のウォレットで確認（署名）します。自動で送ることはしません。進み具合はこのブラウザに保存されるので、画面を閉じても続きから再開できます。

送る元チェーン → 届くチェーン
→ 42 Chain

中継に使えるのはブリッジの実績を確認できたトークンだけです（QOM / BABY / CAW / FATHER / HAWK / KET / O / OSAK。ただし 42 Chain → QL1 の OSAK は送信実績が確認できていないため使えません）。ブリッジがつながっているトークンは、どれでも中継に使えます（仕組みはトークンごとに違いません）。中継ごとに交換の通り道の組み合わせ（全体ルート）を全部並べるので、遠回りなルートがなぜ多いのか・単純なルートだとどれだけ減るのかも、そのまま見て選べます。全体ルート同士で金額を分ける「分割」も見積もりし、単一ルートより多いときだけ分割プランのカードを出します（ブリッジはパートごとに別送信になるので、42 Chain から送る場合のメッセージ代はパートの数だけかかります）。ブリッジ手数料は0です。42 Chain から送るときはメッセージ代（約2.94 [42]、送信時に再取得）が別にかかります。QL1 から送るときは実測で0です。到着は数分かかることがあります（実測では約5分の例あり）。

価格差（裁定）

QL1 と 42 Chain の間で同じトークンの値段がズレていると、「安い方で買って、ブリッジして、高い方で売る」ことで差が取れます（裁定。取引されると価格差は縮んでいきます）。このボードは、基準通貨 QOM で始めて QOM で終わるルートを、全トークン×両方向で実際のルート見積もり（各プールの getAmountsOut）で計算します。目安価格だけの比較は、薄いプールでは嘘になるため使いません。

テストネットでは使えません（QL1のテストネットブリッジは確認できていません）。本番チェーンを選んでください。

金額の目安について：42 Chain 発のブリッジにはメッセージ代（約2.94 [42]、QOM換算で約34.5億 QOM）が固定でかかるため、10億 QOM 以下では 42 Chain 発のルートは手数料だけでマイナスになります。初期値は手数料が約3.5%に収まる 1000億 QOM です。逆に大きすぎる金額では、プールが薄くて値段が大きくズレてマイナスになります。小さい金額では QL1 発（手数料0）の小口の価格差が見えることがあります。

  • 見積もりは今のプールの値段です。ブリッジ中（数分）に値段が動くと、結果は変わります。
  • 価格差は、誰かが取引すると縮んで消えていきます（それが裁定の仕組みです）。表示された差が、実行のときにも残っている保証はありません。
  • 往復は片道よりリスクが大きいです（ブリッジが2回で、値段が動く時間が長くなります）。
  • 差し引きにはブリッジのメッセージ代（QOM換算）を含んでいますが、DEX のガス代は概算のため含んでいません。
  • 買える量がブリッジの最小量（1トークン）に届かないルートは「見積もり不可」と表示します（例：小さい金額での KET）。

CAを貼ってトークンを追加

一覧に無いトークンは、コントラクトアドレス（CA）を貼るとチェーンから読み取って追加できます。追加したトークンはこのブラウザに保存されます。

仕組みと正直な限界

  • 見積もりは DEX ルーターの getAmountsOut を、直接・1つ経由・2つ経由の全ルートで実際に叩いた結果です。推測の価格ではありません。
  • 上位ルートへの分割（90/10、80/20、…、50/50 や3ルート分割）も同じ方法で見積もりし、単一ルートより多いときは「分割プラン（おすすめ）」として出します。
  • 分割の実行には専用のアグリゲーター・コントラクトが必要です。コントラクト（SplitSwap）はこのサイトのリポジトリで公開していて、チェーンごとに自分のウォレットからこの画面でデプロイできます（v7）。デプロイした住所はこのブラウザに保存され、それ以降は分割プランをそのまま実行できます。デプロイしていないチェーンでは分割は見積もりのみで、実行は単一ルートです。テストネットでも同じ方法でデプロイできますが、ガス代に TEST42 が必要です（公開ファウセットは見つかっていません）。各レッグには最低受取量も入ります（v7）。クロスチェーンの分割は、追加のブリッジ代を引いても単一ベストに勝つときだけプランを出します（v6.5）。
  • テストネットの DEX ルーターは、公開記録のアドレスが1文字多く壊れていたため、候補を全部ライブで検証して復旧したアドレスを使っています。トークン一覧もテストネットの実ペアから作っています。
  • 「値段の下がり幅」は、プールの残高から計算した手数料なしの目安と、実際の見積もりとの差です（手数料＋金額の大きさによる影響）。ガスの金額も目安です。
  • プールが小さいトークンでは、見積もりと実際の結果がズレやすくなります。少しの金額で試してから大きな金額を扱ってください。
  • このサイトは手数料を取りません。交換は各チェーンの DEX（42 Chain: Don't Panic／QL1: QomSwap）のルーターと直接やり取りします。
  • 全体ルート表示（v5）：クロスチェーンの結果は「交換1 → ブリッジ → 交換2」を1つに束ねた全体ルート単位で並べます。中継トークンごとに交換の通り道の上位バリアントを組み合わせるので、単純なルート（通るプールが少ない）も、遠回りでも受け取りが多いルートも、両方見て選べます。「このルートではじめる」を押すと、その全体ルートの通り道がそのまま保存され、ステップ1とステップ4は保存された通り道で実行します（実行時にその通り道で見積もり直し、使えなくなっていたら別のルートへは切り替えずに止まります）。
  • クロスチェーン分割（v6〜v6.4）：全体ルート同士で金額を分ける分割も、各パートを「そのルート・その金額」で実際に見積もり直して評価します。候補は最終見積もり順の上位ルートで、同じ中継の異なる通り道（例：USDT → FISH → QOM）も別々に数えます。配分はまず10%刻みで粗く探し（2〜5パート）、ペアは1%刻みで全て試し、最後に1%刻みの微調整で詰めます（微調整では全体ルート一覧のどれでも新しく加えて試します）。同じ中継・同じ2回目の交換になるパート同士は、2回目の交換を「届いた合計額で1回だけ」見積もって分け合うので、同じプールを2回使う分の上振れは出ません（v6.4）。単一ルートより多いときだけ「分割プラン」のカードを出し、「この分割プランではじめる」でパートごとのガイド（交換→ブリッジ→到着待ち→交換をパート単位で進める）が始まります。ブリッジはパートごとに別送信で、42 Chain 発のメッセージ代はパート数分かかります（合計をカードに表示します）。分割が単一に負けるときはプランを出さず、「単一ルートがいちばん」と正直に表示します。実測の対照例：1,000 USDT → QL1 の QOM では分割が単一ベストより +44.5% 多くなり、1,000 USDT → QL1 の qCAW でも中継QOM の2つの通り道を両方使う分割が +48.8% でした。
  • 価格差の表示（v4）：クロスチェーン見積もりでは「素直なルート」（中継 QOM、または出すトークンそのものをブリッジできる場合はそれ）を基準にして、各候補に基準との差（%と量）を表示します。いちばん多い候補が基準より 0.5% 超多いときは「価格差で +○%」のバッジが付きます（例：実測では 42 Chain の 100 [42] → QL1 QOM で、中継 BABY が基準の QOM より +6.33% 多くなりました。ただし 500 [42] では BABY のプールが吸収しきれず −25.8% と逆転します。金額で変わるので、必ず自分の金額で見積もり直してください）。
  • クロスチェーン（v3）：ブリッジは Hyperlane（Zaphod Bridge）を使います。有効にしている向きとトークンは、実在の送信トランザクションからメッセージIDを取り、届け先チェーンのメールボックスで「配達済み」を確認できたものだけです（2026-11-06 サンプリング: QL1→42 Chain は8トークン×2件 = 16/16、42 Chain→QL1 は OSAK を除く7トークンで 13/13 が配達済み。OSAK の 42 Chain 側ルーターには送信実績自体が無いため、この向きだけ無効にしています）。ブリッジ公式サイトの統計で「QL1発の配達0件」と出るのは、その統計の索引が QL1 を拾えていないためで、チェーン上では配達が確認できています。最後の交換は到着時点の値段になるため、最終見積もりは目安です。
