DEXアグリゲーター（42 Chain / QL1）

いちばん多く受け取れるルートを、全部のプールから探します。

「ルート」＝交換の通り道です。たとえば USDT → 42 を直接交換する道と、USDT → FISH → 42 のように途中で別のトークンを経由する道があり、金額によって多い方が変わります。このサイトは全ての道を見積もりして並べます。

チェーン

未接続（見積もりだけなら接続なしで使えます）

交換する

MAX はネイティブ通貨（42 / QOM）の場合、ガス代用に 0.01 だけ残して計算します。トークンの場合は全額です。

スリッページ（値段がズレても許せる幅）

見積もりから実際の値段がこの幅より悪くなったら、取引は自動で失敗して資産を守ります。

交換は有効期限20分で送ります。初めて使うトークンでは、最初に「使う許可」の確認がウォレットに出ます。

CAを貼ってトークンを追加

一覧に無いトークンは、コントラクトアドレス（CA）を貼るとチェーンから読み取って追加できます。追加したトークンはこのブラウザに保存されます。

仕組みと正直な限界

  • 見積もりは DEX ルーターの getAmountsOut を、直接・1つ経由・2つ経由の全ルートで実際に叩いた結果です。推測の価格ではありません。
  • 「値段の下がり幅」は、プールの残高から計算した手数料なしの目安と、実際の見積もりとの差です（手数料＋金額の大きさによる影響）。
  • 分割（例：70%を直接、30%を経由ルートで一度に交換）は実行できません。分割を1回の取引で実行するには専用のアグリゲーター・コントラクトが必要ですが、このチェーンにはまだありません。このサイトでは分割した場合の見積もりだけを「分割したら（参考）」として表示することがあります。
  • プールが小さいトークンでは、見積もりと実際の結果がズレやすくなります。少しの金額で試してから大きな金額を扱ってください。
  • このサイトは手数料を取りません。交換は各チェーンの DEX（42 Chain: Don't Panic／QL1: QomSwap）のルーターと直接やり取りします。
