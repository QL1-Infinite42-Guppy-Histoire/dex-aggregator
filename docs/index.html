クロスチェーン交換（QL1 ⇔ 42 Chain）

別のチェーンのトークンに交換します。進み方は「交換 → ブリッジで送る → 到着を待つ → 最後の交換」の4ステップで、各ステップで自分のウォレットで確認（署名）します。自動で送ることはしません。進み具合はこのブラウザに保存されるので、画面を閉じても続きから再開できます。

CAを貼ってトークンを追加

一覧に無いトークンは、コントラクトアドレス（CA）を貼るとチェーンから読み取って追加できます。追加したトークンはこのブラウザに保存されます。

仕組みと正直な限界

  • 見積もりは DEX ルーターの getAmountsOut を、直接・1つ経由・2つ経由の全ルートで実際に叩いた結果です。推測の価格ではありません。
  • 上位ルートへの分割（90/10、80/20、…、50/50 や3ルート分割）も同じ方法で見積もりし、単一ルートより多いときは「分割プラン（おすすめ）」として出します。
  • 分割の実行には専用のアグリゲーター・コントラクトが必要です。このサイトのリポジトリにはそのコントラクト（SplitSwap）を用意してありますが、42 Chain / QL1 本番にはまだデプロイされていません。そのため本番チェーンでは分割は見積もりのみで、実行は単一ルートです。テストネット用も未デプロイです（デプロイに使う TEST42 の公開ファウセットが見つからなかったため）。デプロイされれば、このサイトの分割ボタンがそのまま使えるようになります。
  • テストネットの DEX ルーターは、公開記録のアドレスが1文字多く壊れていたため、候補を全部ライブで検証して復旧したアドレスを使っています。トークン一覧もテストネットの実ペアから作っています。
  • 「値段の下がり幅」は、プールの残高から計算した手数料なしの目安と、実際の見積もりとの差です（手数料＋金額の大きさによる影響）。ガスの金額も目安です。
  • プールが小さいトークンでは、見積もりと実際の結果がズレやすくなります。少しの金額で試してから大きな金額を扱ってください。
  • このサイトは手数料を取りません。交換は各チェーンの DEX（42 Chain: Don't Panic／QL1: QomSwap）のルーターと直接やり取りします。
  • クロスチェーン（v3）：ブリッジは Hyperlane（Zaphod Bridge）を使います。有効にしている向きとトークンは、実在の送信トランザクションからメッセージIDを取り、届け先チェーンのメールボックスで「配達済み」を確認できたものだけです（2026-11-06 サンプリング: QL1→42 Chain は8トークン×2件 = 16/16、42 Chain→QL1 は OSAK を除く7トークンで 13/13 が配達済み。OSAK の 42 Chain 側ルーターには送信実績自体が無いため、この向きだけ無効にしています）。ブリッジ公式サイトの統計で「QL1発の配達0件」と出るのは、その統計の索引が QL1 を拾えていないためで、チェーン上では配達が確認できています。最後の交換は到着時点の値段になるため、最終見積もりは目安です。
