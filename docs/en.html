DEX Aggregator (42 Chain / QL1 / Testnet)

Finds the route that gives you the most, across every pool. 日本語

A "route" is the path a swap takes. For example, USDT → 42 can go directly, or via another token like USDT → FISH → 42, and which one gives more depends on the amount. This site quotes every path — including "splits" that divide your amount across several routes — and ranks them, the same idea as 1inch.

How it works — and honest limits

  • Quotes are real: the site calls the DEX router's getAmountsOut for every candidate route (direct, 1 hop, 2 hops). Nothing is guessed from a price feed.
  • Splits across the top routes (90/10, 80/20, …, 50/50, and 3-way splits) are quoted the same way. When a split beats every single route, it is shown as the recommended "Split plan".
  • Executing a split needs a dedicated aggregator contract. The contract (SplitSwap) is included in this site's repository, but it is not deployed on 42 Chain / QL1 mainnet yet, so on mainnet a split is a quote only and execution uses a single route. It is also not deployed on the testnet yet (no public TEST42 faucet could be found to pay for deployment gas). Once deployed, the split button on this site works as-is.
  • The testnet DEX router address in public records had one character too many; this site uses the address recovered by verifying every candidate live on-chain. The testnet token list is built from the testnet's real pairs.
  • "Price impact" is the difference between a no-fee estimate from pool reserves and the real quote (fees + size impact). Gas figures are estimates too.
  • Small pools can move between quote and execution. Try a small amount first before swapping a large one.
  • This site takes no fee. Swaps talk directly to each chain's DEX router (42 Chain: Don't Panic / QL1: QomSwap).
